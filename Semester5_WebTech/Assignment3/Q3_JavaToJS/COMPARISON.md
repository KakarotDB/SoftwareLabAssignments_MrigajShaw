# Java vs JavaScript: Syntax Comparison

| Java Concept | JavaScript Equivalent |
|-------------|----------------------|
| `int x = 5;` | `let x = 5;` |
| `System.out.println("Hello");` | `console.log("Hello");` |
| `public class BankAccount` | `class BankAccount` |
| `class Savings extends BankAccount` | `class Savings extends BankAccount` (Same!) |
| `this.field = field;` | `this.field = field;` (Same!) |
| `throws Exception` | `try { ... } catch(e) { ... }` |
| `Scanner.nextLine()` | `document.getElementById("input").value` |
| `new SavingsAccount()` | `new SavingsAccount()` (Same!) |
| `@Override public void func()` | `func()` (No annotation needed, just redefine) |
| `ArrayList<String> list` | `let list = []` (Arrays are dynamic) |
| `double amount` | `let amount` (No strict typing for numbers) |
